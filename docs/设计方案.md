# 文本内容审核群聊插件 — 设计方案（v3）

## 一、概述

监听被管理群中所有纯文本消息，调用本地审核 API（端口 8000）进行违规检测。复用图片审核插件的**双群管理模式**和**智能审查机制**。

核心原则：

- **被管理群干活，管理群看报告+下指令**。所有命令归类到 `/文本审核` 指令组，仅允许在管理群执行。
- **主动群管可关闭，通报不可关闭**：撤回、禁言等主动处置动作均可配置关闭，但违规发生后的管理群通报始终生效。
- **管理员/群主违规不处罚，仅通报**。

---

## 二、审核流程

```
群文本消息到达
  │
  ├─ 消息来源是否为被管理群？否则忽略
  ├─ 消息是否包含纯文本内容？否则忽略
  ├─ 发送者是否为机器人自身？是则忽略
  │
  ▼
【智能审查决策】(见 §三)
  │
  ├─ 不应审查 → 跳过
  │
  └─ 应审查
       │
       ├─ 发送者是白名单用户？是则放行
       ├─ 发送者是管理员/群主？是则放行（skip_admin，默认开启）
       │
       ▼
  调用 POST /audit
       │
       ├─ has_violation: false → 放行
       │
       └─ has_violation: true
            │
            ├─【管理群通报】(始终执行,不可关闭)
            │   格式：【文本违规通知】
            │   群号 + 用户 + 违规内容片段 + 请求ID + 措施说明
            │
            ├─ 发送者是管理员/群主？→ 仅通报，不处罚
            │
            └─ 发送者是普通成员：
                 ├─ 撤回违规消息（可配置关闭, auto_recall）
                 └─ 禁言用户（可配置关闭, auto_mute；时长按累计违规次数递增）
```

**关键点**：`auto_recall` 和 `auto_mute` 只影响普通成员的处置行为。管理群通报不受这两个开关影响。

---

## 三、智能审查模式

与图片审核插件完全相同的三层决策树。

**核心思路**：被动式在线推断 —— "管理员在 N 分钟内发了消息" 视为在线，不依赖平台 API。

**安全优先**：任何异常（无记录、配置缺失、获取身份失败）均回退到"开启审查"。

**决策树**：

```
1. enable_auto_censor == false?  → 全量审查（始终开启）
2. 当前时间在 auto_censor_schedule 内?  → 强制开启
3. last_admin_time 不存在?  → 开启（无记录，安全兜底）
4. elapsed >= auto_censor_no_admin_minutes?  → 开启（管理离线）
5. 否则 → 暂停审查（管理在线）
```

**典型配置**：夜间 23:00-09:00 强制审查，白天管理 30 分钟内有发言则暂停。

## 四、模块分工

| 文件 | 职责 |
|------|------|
| `main.py` | 插件入口。注册 Star 类、绑定消息监听、注册 `/文本审核` 命令组。初始化时创建所有子模块。`on_message` 委托给 `message_handler`。 |
| `config_manager.py` | 配置读写 + 决策引擎。负责：读取全局配置和群配置、判断群是否启用/是否为管理群、按 `manage_group_id` 反向查找被管理群、白名单查询、`should_enable_censor()` 三层决策。 |
| `admin_manager.py` | 管理员检测与发言追踪。缓存管理员列表（5 分钟 TTL），记录每个群最后管理员发言时间。提供缓存查询（在线检测用）和精确查询（命令权限验证用）两种接口。 |
| `audit_client.py` | 审核 API HTTP 客户端。封装 `POST /audit` 和 `GET /health`。支持指数退避重试（最多 3 次）。超时、网络错误返回明确错误状态，不抛异常。 |
| `message_handler.py` | 消息处理编排。串联完整流程：提取群号/用户ID → 过滤非文本消息 → 智能审查决策 → 白名单/管理员豁免 → 调用 audit_client → 违规时调用 violation_handler。 |
| `violation_handler.py` | 违规处置。始终执行管理群通报；根据 `auto_recall` / `auto_mute` 开关和发送者身份（管理员/普通成员）决定是否撤回和禁言；禁言时长按 `first_mute × multiplier^(N-1)` 递增，上限 `max_mute`。 |
| `stats_manager.py` | 数据持久化。管理 SQLite 数据库（audit_log、violation_records、whitelist 三张表），提供增删查接口。路径使用 `StarTools.get_data_dir()`。 |
| `command_handler.py` | `/文本审核` 命令组实现。所有子命令入口先校验 `is_manage_group()`，再按命令分发。权限敏感操作（如删除违规）使用 `is_user_admin()` 精确查询。 |

## 五、配置文件（`_conf_schema.json`）完整定义

### 5.1 API 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `api.base_url` | string | `http://127.0.0.1:8000` | 审核 API 地址 |
| `api.api_key` | string | `""` | API Key（standard 分组即可） |
| `api.timeout` | integer | `10` | HTTP 请求超时，单位秒 |
| `api.max_retries` | integer | `3` | 失败最大重试次数 |
| `api.health_check_interval` | integer | `60` | 健康检查间隔，单位秒；0 表示关闭 |

### 5.2 审核行为配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `audit.enabled` | boolean | `true` | 总开关，关闭后完全不审查 |
| `audit.skip_admin` | boolean | `true` | 是否跳过管理员/群主的消息 |
| `audit.skip_llm` | boolean | `false` | 是否跳过 LLM 复核（仅用关键词+语义） |
| `audit.min_text_length` | integer | `2` | 最短审核文本长度，少于此不审 |

### 5.3 主动群管配置（均可独立关闭）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `action.auto_recall` | boolean | `true` | 是否自动撤回违规消息。关闭后违规消息保留，但仍会通报管理群。 |
| `action.auto_mute` | boolean | `true` | 是否自动禁言违规用户。关闭后不禁言，但仍会通报管理群。 |
| `action.first_mute_duration` | integer | `300` | 首次违规禁言时长，单位秒。`auto_mute=false` 时无效。 |
| `action.max_mute_duration` | integer | `86400` | 最大禁言时长，单位秒。`auto_mute=false` 时无效。 |
| `action.mute_multiplier` | float | `2.0` | 禁言时长递增倍率。第 N 次 = first × multiplier^(N-1)。`auto_mute=false` 时无效。 |

### 5.4 通报配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `notify.mode` | enum | `violation_only` | 通报模式：`violation_only`（仅违规时）、`none`（不通报）。**注意：没有"all"模式，文本审核不通报"通过"的消息。** |
| `notify.show_text_preview` | boolean | `true` | 是否在通报中包含违规文本片段 |
| `notify.preview_max_length` | integer | `100` | 文本预览最大字符数 |

### 5.5 群管理配置（`group_settings`，数组）

每项定义一个"被管理群 → 管理群"的绑定：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enabled` | boolean | `true` | 该群是否启用文本审核 |
| `group_id` | string | — | 被管理群号 |
| `manage_group_id` | string | — | 管理群号（接收通报+执行命令） |
| `enable_auto_censor` | boolean | `false` | 该群是否启用智能审查模式 |
| `auto_censor_schedule` | string | `""` | 强制审查时间段，格式 `hh:mm-hh:mm`，空串=无强制段 |
| `auto_censor_no_admin_minutes` | integer | `0` | 管理员在线检测窗口，单位分钟。0=关闭在线检测 |

### 5.6 白名单配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `whitelist.enabled` | boolean | `false` | 是否启用白名单。关闭后所有用户均受审核。 |
| `whitelist.user_ids` | string[] | `[]` | 白名单用户 QQ 号列表 |

## 六、命令列表（`/文本审核` 指令组）

所有命令仅可在管理群使用，入口校验 `is_manage_group()`。

| 命令 | 说明 | 权限 |
|------|------|------|
| `/文本审核 帮助` | 显示所有子命令及说明 | 无 |
| `/文本审核 状态` | 汇总该管理群下所有被管理群的审核统计（当日/累计违规数、通过数、缓存命中率、API 健康状态） | 无 |
| `/文本审核 状态 <群号>` | 查看指定被管理群的审核统计 | 无 |
| `/文本审核 日志` | 查看最近 10 条违规记录 | 无 |
| `/文本审核 日志 <页码>` | 分页查看违规日志 | 无 |
| `/文本审核 白名单 添加 <QQ号>` | 添加用户到白名单 | 管理员 |
| `/文本审核 白名单 删除 <QQ号>` | 从白名单移除用户 | 管理员 |
| `/文本审核 白名单 列表` | 列出所有白名单用户 | 无 |
| `/文本审核 删除违规 <QQ号>` | 清除指定用户在所有关联被管理群中的违规记录 | 管理员 |

`/文本审核 删除违规` 通过 `get_managed_group_ids(manage_group_id)` 反向查找，遍历所有关联群清理。

## 七、错误处理

| 场景 | 策略 |
|------|------|
| 审核 API 不可用 | 降级放行，日志告警，不阻塞群聊 |
| 撤回失败（机器人无权限） | 通报管理群时标注"撤回失败"，不阻断后续 |
| 禁言失败 | 通报标注"禁言失败"，不影响撤回和通报 |
| 网络超时 | 重试 3 次（指数退避），仍失败则放行 |
| 数据库错误 | 降级为仅通报不记录，日志输出异常 |
