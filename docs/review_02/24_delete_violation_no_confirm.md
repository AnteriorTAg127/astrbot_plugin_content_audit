# 24 — `_delete_violation` 无二次确认

**严重度**：🟢 Minor  
**文件**：`command_handler.py` (行 222-238)

## 问题

`/文本审核 删除违规 <QQ号>` 是一个破坏性操作——它会删除指定用户在**所有关联被管理群**中的全部违规记录。当前实现没有二次确认，管理员输入命令后立即执行删除。

加之该命令没有"撤销"机制，误操作后数据无法恢复。

## 修复建议

增加确认步骤。由于 AstrBot 的指令模型不支持交互式确认（除非使用会话控制器），可采用以下方案之一：

方案 A：要求同时输入用户 QQ 号和确认关键字：

```
/文本审核 删除违规 <QQ号> 确认
```

仅当包含"确认"参数时执行。

方案 B：执行前回复确认信息，包含受影响记录数：

```python
count = await self._stats_manager.get_violation_count_v2(target_qq, managed_groups)
if count == 0:
    return f"⚠️ 用户 {target_qq} 在关联群中没有违规记录"
# 先不删除，返回提示
return f"⚠️ 将删除用户 {target_qq} 的 {count} 条违规记录。请再次输入命令确认: /文本审核 删除违规 {target_qq}"
```

**Why**：误删违规记录无法恢复，增加确认门槛可以避免手误。

**How to apply**：方案 A 最简单，无需状态管理；方案 B 更友好但需要临时存储待确认操作。
